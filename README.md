# Gym Center Membership System

A web-based mini project for managing gym members, trainers, administrators, memberships, and payments.

The main focus of the project is **MySQL database integration, SQL operations, CRUD functionality, and basic role-based authentication**.

## Technologies

- HTML, CSS, JavaScript
- PHP
- MySQL
- phpMyAdmin

## Main Features

- User registration and login
- Admin, Trainer, and User roles
- Member and trainer management
- Membership plan management
- Payment record management
- CRUD operations

## Database

The MySQL database includes tables for:

- Login credentials
- Users
- Admins
- Trainers
- Membership plans
- User memberships
- Payments
- Notifications
- Contact messages

SQL files are available in the `database/` directory.
